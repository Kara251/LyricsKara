# 憧れの残響 — 设计决策与分镜文档

本文档整理 Kara 与 Claude 设计对话中确定的内容，随每次设计推进更新。
创意设计由 Kara 全程主导；Claude 负责工程实现与备选方案。

## 0. 总则（已锁定）

- 定位：**Web 静止系 MAD** —— 以歌曲播放为时间轴的 4:29 实时演出，每句歌词一卡。
- 布局：**全屏沉浸**（非固定画幅）；移动端强制横屏（竖屏遮罩引导）。
- 交互原则：**3D 内容可操控**（用户可拖拽旋转观测角度、旋转对象）；
  **2D 内容不可操控**（文字演出、图片演出不响应指针）。
- 页面 UI 主体英文；标题轮播为 日 / 英 / 中 / 韩 四语。
- 音频：直接播放站内打包音源（无本地文件选择）；`?silent=1` 静默排演供开发。
- 歌词文本以 `src/data/lyrics.js` 为准（BA TW 官译 + Kara 英段中译），纠错后置。

## 1. 开场页（已实现，`src/opening/`）

1. 「憧れの残響」于页面中部略下方由下往上淡入（BA 剧情标题式），停留 1s
2. **标题先行让位**（快速移至封面位，离开中线区，不被线段劈开）；随后正中
   射出一小段竖线（22vh），双边内容如**抽屉**自线段后同时拉出（被中线裁切）：
   左＝封面（标题在其正上方），右＝Staff 与上一级按钮；双边同始同终；
   标题随后以日/英/中/韩轮播
3. 线段消失 → Malkuth 光环**中心点**浮现 → 双边继续靠边让位
4. 光环轮廓自顶部**顺时针加速**发光显现（3D：edge-on 姿态逆时针倾斜 30°，
   22 棱面，形态参考 Malkuth_Halo.png：对称正圆 + 中心一点）
5. 下方浮现 Tap Halo to Continue；其下再一行操作说明
   （Space — play / pause ・ tap or move — progress bar）
6. 点击：内容区自右下向左上**粉末消散**（符合物理学；光环除外——按入场逆序退场）
7. 进入播放器；**开场 → 播放器的过渡演出待定**

参数集中在 `opening.js` 顶部 `T`/`POS`，光环常量在 `malkuthHalo.js` 顶部。
移动端：竖屏进入等转横屏再开演；点击前方向翻转/视口大幅变化则整场重排重演
（地址栏收起类的小幅变化不触发）。

小屏与层级约定（2026-07-06 修订）：光环半径 2.05、管径保持细；**内容区覆盖在
光环之上**（DOM 高于 WebGL 画布），小屏允许双边内容与光环重叠；抽屉裁切仅在
拉出动画期间生效，完成后撤下；靠边距离按内容宽度收敛，不把内容推出屏幕；
线段生长的同时标题即开始让位（不被线段劈开）；窄屏（≤780px）右列限宽换行。

## 2. 前奏 + 主歌一前两句 0:00–32.5「钢铁殿堂 → 沉没的海」（已实现，`src/cuts/intro/sanctum.js`）

一镜到底的连续 3D 世界，横跨前奏与主歌一前两句；相机全程可拖拽。
参考：ED MV 开头（钢铁大陆殿堂的多层破碎光环）与钢铁大陆沉没。

- 舞台：开场过渡结束后，**殿堂自暗场淡入**（0–2.5s）；背景渐变为晴空——
  **上蓝下白的垂直渐变**（0–4s 淡入，`fx/sky.js`）。
- 殿堂（`fx/sanctum.js`）：随机程序化多层同心钢铁光环，**「由好到坏」的崩解演出**——
  **随机生成是 Kara 的设计要求，不是临时替代方案**；随机只负责布局差异，不能退化为
  方块噪声或灰色墙面。前两层钢铁光环半径明显大于下层，第一层更夸张；每个环段由主梁、甲板、侧舱、短支撑、表面内凹面板、
  冷灰刻线与少量
  游离碎片组成，环体更大、更紧凑，色彩限制在冷白 / 雾蓝灰 / 阴影蓝灰，避免褐色
  或暖色嵌板；**每次页面加载随机生成一座新的钢铁殿堂**（会话内种子固定，seek 一致）。
  每簇拥有自己的崩解时刻
  （5.1–22s，后段加速），到点后外抛、翻滚、下坠并收缩消散；部分主块会剥离成
  小钢铁碎片先行坠落。
  **真光环为连续 torus shader**，位置在第三圈外侧且半径略大于第三圈；4.9s 起
  先于钢铁结构以暗淡蜂窝纹理消逝，并由 GPU 粒子云接手，不是金块拼成的环。状态为
  t 的纯函数，seek 安全。
- 相机（`cuts/intro/sanctum.js` 顶部 `CAM` 可调）：
  - 0–11s 近景仰视，置身紧凑机械环带中层（MV 图一）；构图右移 16%——殿堂落在
    2/3 线上（中+右侧），左 1/3 留给 Staff 字幕（ED 式三分构图）
  - 11–14.5s 拉远过渡（俯仰柔性引导，构图回正居中）
  - 14.5–17s 殿堂光环全景（MV 图三）
  - 17–22s **俯冲下降到海平面**：海面与正在沉没的钢铁大陆自下方浮现（俯仰/方位
    引导，落定后释放给用户）
  - 22–32s 海平面近景（构图右移 16%，左 1/3 留给歌词）
  - 全程可拖拽旋转（OrbitControls；禁缩放/平移；距离与注视点由演出接管）
- 天空下半球压暗为雾蓝（`fx/sky.js` uDown），俯视不刺眼。
- Staff 字幕（`cuts/intro/credits.js`）：屏幕左侧，淡蓝描边 + 白色内芯，三批淡入淡出
  （时机 Claude 定，顺序 Kara 定）：Music/Lyrics/Vocal → Translation/Ending Song →
  Website Visual Design。

### 海平面舞台（0:17 起淡入，主歌一前两句的世界）

- **海面**（`fx/sea.js`）：水平大平面，低幅风浪顶点位移 + 沿风向断续延展的浅色风痕
  （`uGust` 由 cut 推入）+ 天空色菲涅尔反射，远处按距离融进天空色、地平线无缝；
  跟随相机 XZ 平移，海无边际。波形是世界坐标纯函数，seek 安全。
- **钢铁大陆**（`fx/continent.js`）：中心在宫殿正下方（世界原点），占地约为宫殿的
  三倍（半径 √3×≈95）；算法分区生成的高低不一钢铁台块 + 低密度顶面楼块/嵌板（可变化大陆
  的不规则体素），中心高、边缘伏成滩。镜头下潜到海平面时大陆整体应明显高于水线，
  低伏边缘也保留离水余量；整块随时间极慢下沉（当前为上一版速度 1/10），
  主歌一内保持“正在被吞没”而不是
  “已经快沉完”。
- **坠物入水**（`fx/fall.js`）：上方殿堂崩落的钢铁块坠海，入水激起扩散环 + 溅起水花；
  0:22–0:28 较大块更小、更慢地下落，坠落途中继续剥离成小钢铁碎片；0:28 起镜头拉远，
  后段碎块转向外围海面，大块先剥离子块、部分子块继续二次裂解，再落海形成外圈涟漪。
  碎块弹道、二次分解、涟漪、水花全为 t 的纯函数（预排程），seek 安全。
- 相机默认框住开海 + 天空 + 坠物，钢铁大陆只在侧边露一小块；上方仍可拖看崩解的殿堂。
- 0:31.2–32.4 世界整体淡出（交棒后续分镜）。

## 2.5 生产播放器控件（`core/player.js`）与中文字幕（`core/subtitle.js`）

- 播放器控制条（底部居中）：播放/暂停按钮 + 进度条（点按跳转）+ 时间码。桌面端鼠标
  移动即显、播放中 3s 无操作自隐；触屏点空白处切换显隐；暂停时保持可见。空格＝
  播放/暂停（全局键）。开场演出期间不出现，进入播放器后激活。
- 中文翻译字幕：**右下角、进度条右侧常驻**，随时间轴切换句子时交叉淡入淡出当前句
  中文译文；2D 不可操控，独立于播放器显隐。
